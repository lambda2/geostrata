Type a keyword (e.g. water, dem, hospital, orthophoto) to find local, national, and global layers intersecting the active map canvas, stream them directly (Enter), or clip and extract them offline to GeoPackage/GeoTIFF (Shift + Enter).
about[fr]=Geostrata intègre un catalogue spatial statique (SQLite R-Tree + FTS5) directement dans la barre de recherche universelle de QGIS (Ctrl+K, préfixe gst). Tapez un mot-clé (ex: eau, dem, hopital, orthophoto) pour trouver les couches locales et mondiales qui intersectent l'emprise actuelle du canevas, les charger en streaming (Entrée) ou les extraire hors-ligne en GeoPackage/GeoTIFF (Maj + Entrée).
version=1.1.0
changelog=1.1.0
    - Large files no longer freeze QGIS: ZIP archives and GeoJSON files are downloaded by a cancellable background task with a progress bar, then kept in a local cache (second load is immediate and works offline, interrupted downloads resume, a changed remote file is downloaded again). Cache folder, size limit (10 GB by default) and "Delete the downloaded files" are in the settings. Offline extraction (Shift+Enter) uses the same cache.
    - New source types: ArcGIS Feature Service and ArcGIS Map/Image Service.
    - Dated layers: sources with a {time} template load the image of the day (or month); the date is shown in the layer name and in the details. Extra WMS/WMTS parameters such as TIME are now sent to the server.
    - Catalog entries can select a sub-layer of a GeoPackage and a geometry type in mixed files.
    - Overpass recipes can return real polygons (closed ways and multipolygon relations) instead of centre points.
    - Bilingual interface (English / French) following the QGIS language, with a language setting.
    - Search results ranked by text relevance, locality and curated priority; works without SQLite FTS5.
    - Preview before loading: coverage footprint on the map, zoom to coverage, details panel (provider, license, format, data date, link status).
    - Fix: WMS layer and style names containing ':' on QGIS 3.x.
